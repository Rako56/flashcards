<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vercel CDN → end user | TLS terminates at Vercel; HSTS enforces HTTPS |
| DNS registrar → Vercel nameservers | Domain control moves to Vercel for wildcard SSL |
| Vercel ENV vars → serverless functions | Service role + Asaas keys must be production-only, never bundled |
| Vercel preview deploys → forked PRs | Forked PRs do NOT get production secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1.12-01 | Information Disclosure | SUPABASE_SERVICE_ROLE_KEY in NEXT_PUBLIC_* | CRITICAL | mitigate | ENV var explicitly NOT prefixed; Vercel UI clarifies "NEXT_PUBLIC_ vars are bundled to client"; manual verification when adding |
| T-1.12-02 | Information Disclosure | Sourcemap leak | HIGH | mitigate | Sentry uploads sourcemaps via auth token; Vercel does NOT serve *.map publicly by default |
| T-1.12-03 | Tampering | Forked PR runs with production secrets | HIGH | mitigate | GitHub default: secrets NOT exposed to forked PR workflows (verified in Plan 1.5 Task 4 Step C); Vercel preview deploys for forked PRs use preview-tier env only |
| T-1.12-04 | Tampering | Wildcard subdomain spoofed via DNS misconfiguration | HIGH | mitigate | Vercel nameservers required for wildcard SSL; only Vercel can issue certs for subdomains (Let's Encrypt DNS-01 challenge) |
| T-1.12-05 | DoS / Information Disclosure | Crawler indexes /admin or /api endpoints | MEDIUM | mitigate | public/robots.txt disallows; HTTP 401 on admin in P8; explicit noindex on admin pages in P8 |
| T-1.12-06 | Spoofing | Browser doesn't enforce HTTPS | MEDIUM | mitigate | HSTS header `max-age=63072000; includeSubDomains; preload` in vercel.json |
| T-1.12-07 | Tampering | Clickjacking via iframe | MEDIUM | mitigate | X-Frame-Options: DENY |
| T-1.12-08 | Tampering | MIME sniffing | LOW | mitigate | X-Content-Type-Options: nosniff |
| T-1.12-09 | Information Disclosure | Referrer leaks to external | LOW | mitigate | Referrer-Policy: strict-origin-when-cross-origin |
| T-1.12-10 | Information Disclosure | Camera/mic/location permissions auto-granted | LOW | mitigate | Permissions-Policy: camera=(), microphone=(), geolocation=() |
</threat_model>
