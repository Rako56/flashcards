<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client-side read-modify-write | Forbidden for any counter; use Postgres functions |
| Webhook redelivery | Same event_id may arrive multiple times — PK enforces idempotency |
| append-only audit logs | No UPDATE/DELETE policies — RLS denies modification by default |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1.8-01 | Information Disclosure | Missing RLS on a table exposes rows | CRITICAL | mitigate | Every table includes ENABLE ROW LEVEL SECURITY + ≥1 policy (except webhook_events which is service-role-only by design); Task 6 verifies via pg_policies |
| T-1.8-02 | Tampering | Read-modify-write on XP loses counts in concurrency | CRITICAL | mitigate | `fn_award_xp` atomic with idempotency_key + UNIQUE (user_id, idempotency_key) on xp_events |
| T-1.8-03 | Tampering | Webhook redelivery duplicates grant | CRITICAL | mitigate | `webhook_events.event_id` is PK (Asaas-provided UUID); INSERT ON CONFLICT DO NOTHING in P4 handler |
| T-1.8-04 | Tampering | refund_requests table doesn't exist (legacy SEC-10) | CRITICAL | mitigate | 0008 creates the table with FK + status enum + RLS; UI write in P4 |
| T-1.8-05 | Tampering | simulado double-submission | HIGH | mitigate | UNIQUE (attempt_id, question_id) on simulado_answers (per 0007) |
| T-1.8-06 | Tampering | append-only audit modified | HIGH | mitigate | srs_reviews + legal_audit_log + audit_log have NO UPDATE/DELETE RLS policies (RLS denies by default when no policy matches) |
| T-1.8-07 | Information Disclosure | service_role + missing search_path = security risk | HIGH | mitigate | All functions use `SET search_path = public` |
