## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service_role key → bundle | service_role bypasses RLS; one leak = entire DB compromised |
| supabase.auth.getSession() vs getUser() | getSession() returns stale cookie data; getUser() validates with Auth server |
| supabase Pro Dashboard → external | Manual config (HIBP, PITR, branching) requires Rafael; not auditable via API in P1 |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-1.6-01 | Information Disclosure | service_role key in NEXT_PUBLIC_* env | CRITICAL | mitigate | Env name explicitly NOT prefixed `NEXT_PUBLIC_`; ESLint `no-restricted-imports` blocks; `'server-only'` import (Next.js compile-time error if bundled); runtime `if (typeof window !== 'undefined') throw` |
| T-1.6-02 | Information Disclosure | Sentry breadcrumb leaks service_role | HIGH | mitigate | Pino `redact: ['*.token']` (Plan 1.10); `Sentry.beforeSend` scrubs (Plan 1.10) |
