<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → git → repo | Untrusted code can be committed without quality gates |
| pre-commit hook → CI | Pre-commit may be bypassed via `--no-verify`; CI is the unbypassable gate (added in 1.4) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1.2-01 | Tampering | `: any` / `as any` casts erode type safety | HIGH | mitigate | ESLint `@typescript-eslint/no-explicit-any: 'error'` + `no-unsafe-*: 'error'` block at lint stage; pre-commit fails locally; CI fails PR (1.4) |
| T-1.2-02 | Tampering | Hardcoded UUID for concurso bypasses access check | HIGH | mitigate | ESLint `no-restricted-syntax` with regex pattern detecting UUID literals; forces `getConcursoBySlug()` use (RESEARCH.md Pitfall P11 + PITFALLS) |
| T-1.2-03 | Information Disclosure | `console.log` ships PII to browser console or stdout | MEDIUM | mitigate | ESLint `no-console: ['error', { allow: ['warn', 'error'] }]`; Sentry + pino are the prescribed alternatives (Plan 1.8) |
| T-1.2-04 | Tampering | service_role import leaks to client bundle | HIGH | mitigate | ESLint `no-restricted-imports` pattern blocks `*/lib/supabase/admin` from non-RouteHandler/non-ServerAction paths; runtime `'server-only'` import + window check is belt-and-suspenders (Plan 1.5) |
| T-1.2-05 | Repudiation | Pre-commit bypassed via `--no-verify` | LOW | accept | CI gate (Plan 1.4) is unbypassable; `--no-verify` requires conscious developer choice + PR will fail CI |
| T-1.2-SC | Tampering | New ESLint plugins from npm install | MEDIUM | mitigate | All plugins listed in RESEARCH.md §Package Legitimacy Audit are [VERIFIED: official] (eslint, typescript-eslint, @next/eslint-plugin-next, eslint-plugin-react-hooks, prettier, prettier-plugin-tailwindcss, husky, lint-staged) |
</threat_model>
